# References for this web app

Put permitted screenshots, logos, typography examples, and product imagery here. Use simple descriptive names such as `navigation-example.png` or `brand-logo.svg`. These are source references; generated application assets belong in the chosen framework's actual asset location after implementation.

## How to describe a reference

In [DESIGN](../../docs/DESIGN.md), record:

- The URL or filename.
- The specific quality to borrow: hierarchy, type, layout, imagery, density, or motion.
- What is unsuitable for this product.
- Ownership, permission, licensing, or required attribution.

Example note: "Borrow this navigation's clear grouping, but keep our own typography and content." A reference is guidance, not permission to copy protected assets or a complete product.

Use realistic content. Do not put secrets, customer records, or private account screenshots here unless their use is appropriate and authorized.
